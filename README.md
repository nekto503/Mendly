# Онлайн дневник/заметки

https://mendly.space-z.ai

MINDLY — место для твоих мыслей: сайт-история и блокнот, который живёт в браузере. Записывай на телефоне — открывай на компьютере. Markdown, вложения, папки, избранное, граф связей и экспорт в PDF.

## Технологии

- Next.js 16 (App Router) + TypeScript
- Tailwind CSS 4 + shadcn/ui
- Prisma + SQLite (база — обычный файл, ставить сервер БД не нужно)
- GSAP + ScrollTrigger + Lenis — скролл-история на главной

## Как запустить у себя

1. Установи Node.js 20 или новее (или Bun).
2. Установи зависимости:
   ```
   npm install
   ```
   (для Bun: `bun install`)
3. В корне проекта создай файл `.env` со строкой:
   ```
   DATABASE_URL=file:../db/custom.db
   ```
   Можно просто переименовать готовый `.env.example` в `.env`. Путь считается от папки `prisma/`, поэтому `../db/custom.db` — это файл `db/custom.db` в корне проекта.
4. Создай базу данных:
   ```
   npm run db:push
   ```
5. Запусти сайт:
   ```
   npm run dev
   ```

Сайт откроется на http://localhost:3000.

## Что выкладывать на GitHub

В репозиторий идут все файлы проекта, кроме служебных — они уже перечислены в `.gitignore`:

- `node_modules/` и `.next/` — огромные и собираются автоматически из кода;
- `db/*.db` — личная база с аккаунтами и заметками, её выкладывать не нужно;
- `dev.log`, `server.log` — журналы запуска;
- `tool-results/`, `agent-ctx/`, `upload/`, `download/` — рабочие файлы песочницы.

## Почему сайт нельзя открыть на GitHub Pages

GitHub Pages показывает только статические файлы без сервера. У MINDLY есть серверная часть: аккаунты, заметки и вложения хранятся в базе на сервере, вход и регистрация идут через API. Поэтому «как есть» на GitHub Pages сайт работать не будет — страница откроется, но войти в аккаунт и сохранить заметку не получится.

Если захочешь показать сайт в интернете, а не только у себя — подойдут хостинги для Next.js (Vercel, Render, Railway). Для базы на таком хостинге лучше использовать внешнюю БД (например, Turso — совместима с SQLite) или тариф с постоянным диском.
